

                              Automation Testing of Demo Web Shop Website Using Playwright
                             ---------------------------------------------------------------

This project is based on automation testing of the Demo Web Shop website using Playwright.

Demo Web Shop is an e-commerce website where users can register, login, search products, browse categories, view product details, add products to shopping cart and wishlist, manage their account information, place orders, and interact with different website features such as contact forms, newsletters, and product reviews.

The objective of this project is to automate the testing of critical business functionalities and verify that all features are working correctly across different browsers.



The project demonstrates various automation testing concepts including:

1. Functional Testing
2. UI Testing
3. End-to-End Testing
4. Data Driven Testing
5. Cross Browser Testing
6. Page Object Model (POM)
7. Reusable Utilities
8. Test Data Generation
9. Assertions & Validations
10.GitHub Integration
11.CI/CD Ready Framework
