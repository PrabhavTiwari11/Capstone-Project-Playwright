Project Title : 
-----------------
Automation Testing of nopCommerce Demo Store Website Using Playwright

This project is based on automation testing of the nopCommerce Demo Store website using Playwright.
nopCommerce Demo Store is an online shopping website where users can register, login, search products, add items to cart or wishlist, place orders, manage addresses, and complete payments.

In this project, different features of the website will be tested automatically using Playwright.
The main purpose of the project is to check whether all important functionalities of the website are working properly or not. The testing includes modules like login, registration, product search, shopping cart, wishlist, checkout, payment, and user profile management.

This project is created as a QA automation capstone project to learn and demonstrate different testing concepts such as functional testing, UI testing, regression testing, API testing, and cross-browser testing in a simple and practical way.
